# Lintar Hub

Personal App Launcher berbasis Next.js untuk mengumpulkan semua aplikasi/project dalam satu tempat.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Menjalankan project

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Mengganti daftar aplikasi

Edit `data/apps.ts`. Untuk sementara URL contoh masih menggunakan `#` agar aman. Ganti setiap `url` dengan URL Vercel, Google Apps Script, atau aplikasi lain milik Anda.
